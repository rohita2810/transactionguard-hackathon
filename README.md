# 🛡️ TransactionGuard

Synthetic business-transaction monitoring with autonomous recovery.
A robot places test orders, detects the failing step, heals the service automatically and proves the fix.

## Run
Open `index.html` in any browser (or use the VS Code *Live Server* extension).

## Files
- `index.html` - page structure and content
- `style.css` - design, layout, animations
- `script.js` - live demo logic (robot, failures, auto-recovery, live inventory)

Built for the Business Automation Hackathon. Services and failures are simulated in the browser.
